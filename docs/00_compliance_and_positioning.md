# 00. 合规边界与业务定位

## 一句话结论

这门生意不能以“低价 token 转售”作为主定位。更稳、更有利润、更容易做大的定位是：

```text
LLM API Gateway + 模型路由 + 成本优化 + AI 工作流交付服务
```

以及海外合规场景下的：

```text
Coding Agent Workflow Infrastructure
```

## 两条业务线必须拆开

### A 线：国内合规线

主打：

- Kimi / Moonshot API。
- 国产合规模型。
- 模型网关。
- API 成本优化。
- AI 功能上线陪跑。
- 系统集成商白标模型基础设施。

客户：

- 国内 AI 应用创业团队。
- SaaS/企业软件公司。
- 系统集成商。
- 外包开发团队。
- 内部 AI 工具团队。

不要宣传：

- 国内可用 OpenAI/Codex。
- ChatGPT 5.5 token 代售。
- 绕地区限制访问。
- 出售 API key、账号、额度。

### B 线：海外支持地区线

主打：

- Codex / GPT coding 能力的合规应用接入。
- Coding agent workflow。
- GitHub/GitLab/Linear/Slack 接入。
- PR review、issue to PR、CI repair。
- 成本、日志、权限、安全审计。

客户：

- OpenAI 支持地区的软件团队。
- 海外 SaaS/AI 创业团队。
- Dev agency。
- Devtool 公司。
- 开源项目背后的公司。

不要做：

- 账号转卖。
- API key 转卖。
- 国内绕限制使用。
- 无 KYC 的个人 token 零售。

## 为什么不要卖裸 token

裸 token 生意有几个天然问题：

- 客户只会比价。
- 毛利不断被压缩。
- 没有产品黏性。
- 客户可以随时换供应商。
- 风控和合规风险高。
- 很难形成案例和长期信任。

而模型网关/工作流服务可以形成：

- 客户系统接入成本。
- 用量和日志沉淀。
- 成本优化报告。
- 权限和团队管理。
- 真实业务案例。
- 月费和增值服务。

## 合规准入表

每个客户进入前，至少确认：

```text
公司/团队名称
联系人
地区
业务用途
是否拥有被处理数据/代码的合法权限
是否涉及敏感/违法/灰色用途
使用模型类型
是否需要跨境服务
预估调用量
是否需要企业服务条款
```

## 红线

不要服务这些需求：

- 购买或转卖账号/API key。
- 批量绕过地区、额度、风控。
- 灰产内容生成。
- 欺诈、钓鱼、刷量、恶意爬虫。
- 没有代码授权却要求分析私有代码。
- 要求隐藏付费推广关系。

## 对外定位话术

不要说：

```text
我们有便宜 token。
我们能卖 Codex/ChatGPT 5.5 API。
国内也能用。
```

要说：

```text
我们帮 AI 应用团队用 Kimi/合规模型更快上线 AI 功能，并通过模型网关控制成本、稳定性、权限、日志和账单。
```

或者：

```text
We help software teams plug coding agents into GitHub, Linear, Slack, and CI workflows, turning issues, reviews, and CI failures into auditable PR drafts.
```
