# 06. Lead Finder MVP 作战手册

## 这版 MVP 的定位

Lead Finder MVP 不是自动营销工具，也不是私信群发器。它的正确定位是：

```text
公开线索发现 + 去重 + 痛点评分 + 客户分层 + 触达话术生成 + CRM 导出
```

它只做获客链路里的前半段：

```text
发现线索 -> 判断价值 -> 生成触达角度 -> 导出 CRM
```

它不做：

```text
自动私信
刷评论
抓私人信息
绕平台风控
批量骚扰
```

这个边界非常重要。它让我们可以把 Lead Finder 当成合规的“买家信号雷达”，而不是平台眼里的 spam 工具。

## 与前面方法论的关系

之前的方法论核心是：

```text
把获客当成交易组合管理。
先找高痛感、高 LTV、7 天可验证的客户。
用诊断/audit 切入。
把结果变成案例。
每周复盘渠道，给赢家加仓。
```

Lead Finder MVP 正好承担其中的第一步：

```text
发现高意向买家信号
```

它把“我去哪里找客户”变成可重复流程：

```text
公开种子源
  -> 搜索扩展
  -> 去重
  -> 痛点识别
  -> S/A/B/C 分级
  -> 生成个性化话术
  -> 导出 CRM
  -> 人工触达和诊断
```

## S/A/B/C 分级后怎么处理

### S 级

定义：

```text
明确表达购买/配置/替代/稳定性需求
有公开联系入口
痛点与产品高度匹配
7 天内可验证
```

动作：

```text
24 小时内人工个性化触达
提供免费诊断/audit
约 15-30 分钟沟通
进入 CRM
```

### A 级

定义：

```text
需求较明确，但付费能力或决策人不确定。
```

动作：

```text
发送轻量技术资料
邀请提交配置/日志做诊断
观察回复
```

### B 级

定义：

```text
有相关兴趣，但购买信号弱。
```

动作：

```text
纳入内容分发池
用教程、checklist、开源工具触达
暂不销售推进
```

### C 级

定义：

```text
相关性弱、低付费、灰色需求或难验证。
```

动作：

```text
暂缓
不投入人工销售时间
```

## Lead Finder 输出后的人工流程

每天流程：

```text
09:30 自动跑 Lead Finder
10:00 查看 Markdown 报告
10:30 筛选 S/A 级线索
11:00 人工补充背景信息
14:00 发出个性化触达
17:00 记录回复和下一步
18:00 更新 CRM 状态
```

每条 S/A 线索必须人工补充：

```text
这个人/项目为什么现在可能需要我们？
最可能的痛点是什么？
我们能给他的第一个低摩擦 offer 是什么？
是否有合规风险？
下一步要让他提交什么材料？
```

## 关键提醒

Lead Finder 不是替代销售，而是让销售每天从高意向信号开始。

最容易失败的方式：

```text
拿 CSV 群发私信
只看数量不看质量
不做人工背景补充
不提供低摩擦诊断
不记录回复和成交数据
不复盘来源质量
```

正确方式：

```text
工具发现信号
人工判断意图
用诊断切入
把诊断结果产品化
把成交案例反馈给关键词和评分规则
```
