# Lead Finder Daily SOP

## 早上：运行和筛选

```powershell
.\run_lead_finder.ps1 -Limit 50 -IncludeGitHub
```

查看：

```text
Markdown 报告
CSV CRM 表
JSON 结构化数据
SQLite 历史库
```

筛选顺序：

```text
1. S 级
2. A 级
3. GitHub one-api / gateway 相关
4. LINUX DO / V2EX 真实需求帖
5. 掘金/B站教程作者
```

## 中午：人工补充

每条 S/A 线索补充：

```text
客户是谁？
他现在遇到什么问题？
他是否有付费能力？
是否合规可做？
第一句话怎么个性化？
给他的低摩擦 offer 是什么？
```

## 下午：触达

每天目标：

```text
S 级：全部触达
A 级：10-20 条
B 级：不私信，纳入内容池
```

触达原则：

```text
不群发
不硬广
不承诺绕限制
不谈灰色能力
先给诊断，不先报价
```

## 晚上：记录和复盘

记录：

```text
是否回复
是否有效对话
是否提交配置/日志/repo
是否进入诊断
是否报价
是否成交
拒绝原因
下一步
```

复盘问题：

```text
今天哪个来源质量最高？
哪个关键词带来的线索最接近买家？
哪个话术回复最好？
哪些线索其实是低质量？
评分规则要不要调整？
```

## 每周五：加仓/减仓

加仓：

```text
高回复率来源
高 S/A 占比关键词
能进入诊断的用户群
能成交的 ICP
```

减仓：

```text
只问低价
灰色需求多
无回复
无付费能力
无法 7 天验证
```

## 每周输出物

```text
1 份 Top 20 线索复盘
1 份来源质量排名
1 份话术效果排名
1 份诊断/audit 结果
1 个可转内容的客户问题
```
