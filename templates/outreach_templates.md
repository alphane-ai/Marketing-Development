# Outreach Templates

## Kimi/API Gateway - 国内 AI 应用团队

```text
你好，我看到你们最近在做 [具体 AI 功能/产品更新/招聘]。

这个阶段通常会遇到两个问题：
1. 模型调用成本开始不可控；
2. 单模型接入后，稳定性、fallback 和用量统计很难补。

我们在做面向 AI 应用团队的 Kimi/API 模型网关，可以做统一调用、用量统计、fallback、团队额度和成本优化。

如果你愿意，我可以先帮你们免费做一次 7 天成本体检：
看典型 prompt / 调用结构，不需要接入生产环境，最后给一份节省建议。
```

## Codex/Coding Agent - SaaS CTO

```text
Hi [name],

I saw that you are hiring engineers and shipping fast.

A pattern we see in small SaaS teams is that senior engineers spend too much time on small bugs, PR review, CI failures, and repetitive implementation tasks.

We help teams plug Codex-style coding agents into GitHub/Linear/Slack so these tasks become auditable PR drafts instead of backlog items.

Would you be open to a free 30-minute workflow audit? We can look at 3 historical issues/PRs/CI failures and estimate how many engineer-hours could be saved each month.
```

## Follow-up 1

```text
补充一句：这个不是让你们直接换模型或重写系统。

我们的第一步只是做诊断/audit：
看现有 prompt/调用日志/repo 任务，判断哪里最容易节省成本或工程师时间。

如果看不出明确价值，就不继续。
```

## Follow-up 2

```text
我可以把诊断范围压得很小：

Kimi/API：3 个典型 prompt 或一小段匿名调用日志。
Codex：3 个历史 issue / PR / CI failure。

输出就是一页报告：可优化点、预计节省、风险和 7 天试点方案。
```
